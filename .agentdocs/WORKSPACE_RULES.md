# 工作区规则（本地 Cursor 工作区级约束）

> 本文档是 Cursor 工作区规则 `d:\MicrobotNew\CLAUDE.md` 的内容镜像。
> 由于 Windows 默认大小写不敏感，`CLAUDE.md` 与上游跟踪的 `CLAUDE.MD` 会冲突，所以规则实际写到此处，并在每次启动会话时由父代理加载。
> 这是 **Cursor 工作区级** 规则，不是仓库代码；不会进入 Git 提交。

## 沟通与语言
- 与用户的回复、文档、代码注释均使用中文；必要时保留英文专业名词并在首次出现时附中文注释。

## 代理角色边界
- **审查 / 检查 / 分析类任务**：只读代码、运行测试、输出报告，绝不修改任何文件。
- 只有用户明确要求"修改 / 实现 / 修复 / 重构"时，代理才可动代码。
- 发现问题时只报告，不擅自修复。

## 危险 Git 命令
- `git reset --hard`、`git push --force`、`git checkout -- .`、`git clean -f`、`git rebase`、`git branch -D` 等命令必须先向用户说明意图，得到明确许可后才能执行。

## 代码质量
- 不编写"兜底代码"：禁止空 catch 吞异常、禁止失败时返回默认值绕过错误。
- 异常必须向上抛出（fail-fast），异常信息必须说清哪里失败、为什么失败。
- 单文件不超过 3000 行；优先复用现有成熟代码。
- 重构先提案后执行；批量改动前先读后改。

## 临时文件
- 临时文件统一存放在项目 `.tmp/` 目录或系统临时目录，命名以 `tmp-` 前缀开头。
- 任务完成后必须清理本次产生的临时文件；无法清理的列出清单告知用户。

## 任务文档
- 复杂任务必须在 `.agentdocs/workflow/` 下创建任务文档（命名 `YYMMDD-任务简述.md`）。
- 任务结束后按"任务回顾"清单核对：清理临时文件、更新文档 TODO、必要时归档到 `.agentdocs/workflow/done/`。

## 项目仓库内的代码规则
- 项目根目录的 `AGENTS.md`（RuneLite/Microbot 上游约定）是代码相关规则的唯一来源，进入仓库前必读。
- 本地工作区规则不会上传到 GitHub 仓库，团队成员各自维护一份本文件。
